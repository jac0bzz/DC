01 / QUIENES SOMOS

INGENIERÍA PARA EL SECTOR PETROLERO.

Somos una empresa especializada en el diseño y fabricación metalmecánica para la industria del petróleo y el gas. Operamos en Colombia y avanzamos bajo los estándares de la norma API 4F para la producción de mástiles, subestructuras y equipos destinados a operaciones de perforación y mantenimiento. Nuestro compromiso con la calidad, respaldado por procedimientos rigurosos y un equipo altamente calificado, nos permite entregar soluciones confiables, seguras y de alto desempeño para nuestros clientes.

NUESTROS
SERVICIOS

01 / CERTIFICACIÓN API

CATEGORÍA III Y IV

Ejecutamos inspecciones estructurales exhaustivas bajo el estándar API RP 4G. Realizamos mantenimientos de Categoría III (visual detallada) y Categoría IV (desmontaje mayor y pruebas END/NDT) para recertificar la integridad de mástiles y subestructuras.

02 / OPTIMIZACIÓN

UPGRADES

Modernización integral de activos para incrementar la capacidad de carga (Hook Load) y la eficiencia operativa. Actualizamos subestructuras, mástiles y sistemas de control integrando tecnología de última generación sin necesidad de adquirir equipos nuevos.

03 / OPERACIONES

DISEÑO

Desarrollamos ingeniería conceptual, básica y de detalle bajo normativas API. Modelado 3D, simulación de cargas y análisis de elementos finitos (FEA) para garantizar estructuras invulnerables.

04 / TECNOLOGÍA

FABRICACIÓN

Construcción metalmecánica pesada con aceros de alta resistencia, soldadura certificada y rigurosos ensayos no destructivos (NDT) para la industria energética global.

05 / LOGÍSTICA

MANTENIMIENTO

Recertificación de equipos, inspección estructural, modernización de componentes (Retrofit) y logística de ensamblaje en sitio para operaciones ininterrumpidas.
